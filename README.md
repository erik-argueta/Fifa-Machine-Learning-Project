# (Forked) FIFA Dataset

The goal of this project is to apply linear regression to this dataset.  

## Link to File:  
https://www.kaggle.com/competitions/mb4011-fifa-player-value-prediction/data?select=PlayerStat-Test.csv

# Goal 
Demonstrate how changes in a player's attributes affect the market value.  

# Milestones 
1. Prediction Functionality
    - Load trained Random Forest in a standalone Python script and confirm that changing an input produces valid predictions. 
    - Save and load the complete preprocessing pipeline to ensure consistent results.
2. What-if analysis (centerpiece)
    - Write a function that takes one player, modifies a selected attribute, and calculates predictions across a range of values. This is the core functionality of the visualization. 
3. Interactive GUI
    - Build sliders for the nine features, display the original and modified predictions, and add a graph showing the attributes influence.
